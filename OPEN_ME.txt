Covista Campus Greenfield — Programming & Master Planning Dashboard
====================================================================

HOW TO OPEN THE DASHBOARD
-------------------------
• Double-click "Open Dashboard.bat" to open the dashboard in your browser.
  — or —
• Double-click "index.html" to open it in your default web browser.

Keep this entire folder when sharing or moving (index.html + images + this file).
No internet is required for the dashboard logic; images and charts work offline
once the page is open (fonts and chart library load from the internet if available).

GITHUB PAGES (MAP)
------------------
If the map is missing on https://dwieberdink.github.io/MarshallSOM/ :
1. GitHub repo → Settings → Pages → Build and deployment → Source: GitHub Actions
2. Confirm secret MAPBOX_ACCESS_TOKEN is set under Settings → Secrets and variables → Actions
3. Re-run the "Deploy GitHub Pages" workflow under the Actions tab if needed
